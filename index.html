 Backup & settings

Automatic sync & backup (private GitHub repo)

Not connected.

When connected, your data syncs to that private repo on your GitHub account. A copy of each day is kept for 30 days, and GitHub also keeps the full change history. The token is stored only in this browser.

Without sync connected, your data lives only on this device, so save a backup regularly.
